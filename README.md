
# BLOCKCHAIN PROJECT

## HỆ THỐNG BỎ PHIẾU ĐIỆN TỬ PHI TẬP TRUNG (D-VOTING)

### 1. Giới thiệu đề tài

D-Voting là hệ thống bỏ phiếu điện tử ứng dụng công nghệ Blockchain và Smart Contract nhằm hỗ trợ quá trình tổ chức, quản lý và kiểm tra kết quả bỏ phiếu.

### 2. Mục tiêu

- Xây dựng hệ thống bỏ phiếu điện tử.
- Đảm bảo mỗi ví chỉ được bỏ phiếu một lần trong mỗi cuộc bầu cử.
- Lưu trữ kết quả bỏ phiếu trên Blockchain.
- Hỗ trợ quản lý cuộc bầu cử và ứng viên.

### 3. Công nghệ dự kiến

- Solidity
- Ethereum
- Remix IDE
- MetaMask
- HTML, CSS, JavaScript
- Ethers.js
- GitHub

- Thành viên 2: Võ Hoàng Nhã

### 5. Chức năng chính

- Quản trị cuộc bầu cử.
- Quản lý danh sách ứng viên.
- Đăng ký địa chỉ ví được quyền bỏ phiếu.
- Kết nối ví MetaMask.
- Thực hiện bỏ phiếu.
- Kiểm tra kết quả bỏ phiếu.
